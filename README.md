# Gdzie zjeść

Prywatna aplikacja PWA do przeglądania restauracji, pubów, barów, klubów i kawiarni w Lublinie: zdjęcia, adres, ocena, godziny, opinie, menu i link do strony lokalu. Niczego nie rezerwuje i nic nie zbiera, tylko wyświetla dane.

- Aplikacja: pliki w głównym folderze (HTML, CSS i JS bez kompilacji), publikowana przez GitHub Pages.
- Dane: `data/places.json`, budowane przez skrypty z `collector/`.
- Notatki do dalszej pracy: `KONTYNUACJA.md`.
